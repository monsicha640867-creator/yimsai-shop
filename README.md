# ยิ้มใส YIMSAI — แลนดิ้งเพจขายยาสีฟัน

ร้านขายยาสีฟัน 3 SKU → ออเดอร์เก็บใน Google Sheet → หลังบ้านใช้ **หยิบ → แพ็ค → พิมพ์ใบปะหน้า**

## โครงสร้างไฟล์
```
index.html          หน้าขายสินค้า (ลูกค้า)
admin.html          หลังบ้าน: หยิบ / แพ็ค / ใบปะหน้า
config.js           ⭐ ตั้งค่าร้าน (URL, สินค้า, ผู้ส่ง)
css/  js/           สไตล์ + โค้ด
images/             📁 โฟลเดอร์เก็บรูปแยก (logo, hero, products/)
apps-script/Code.gs โค้ดสำหรับ Google Sheet
```

| SKU | สินค้า | ราคา | ชั้นวาง |
|---|---|---|---|
| YS-MINT-160 | เฟรชมินต์ 160 ก. | 89 | A-01 |
| YS-CHAR-160 | ชาร์โคล ไวท์ 160 ก. | 109 | A-02 |
| YS-KIDS-80 | คิดส์ สตรอว์เบอร์รี 80 ก. | 69 | B-01 |

## ขั้นที่ 1 — Google Sheet
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม → วางโค้ดจาก `apps-script/Code.gs`
3. แก้ `ADMIN_KEY` เป็นรหัสของเราเอง → กด 💾
4. เลือกฟังก์ชัน `setup` → กด **Run** → อนุญาตสิทธิ์ (จะได้แท็บ `Orders` พร้อมหัวตาราง)
5. **Deploy → New deployment → Web app**
   - Execute as: **Me** · Who has access: **Anyone**
6. คัดลอก URL (ลงท้าย `/exec`) → วางใน `config.js` ช่อง `SCRIPT_URL`

> แก้ Code.gs ทีหลัง ต้อง **Deploy → Manage deployments → Edit → New version** ทุกครั้ง

## ขั้นที่ 2 — GitHub
1. github.com → **New repository** (เช่น `yimsai-shop`)
2. **Add file → Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมดขึ้นไป (โฟลเดอร์ `images/` ต้องไปด้วย)
3. กด **Commit changes**

## ขั้นที่ 3 — Vercel
1. vercel.com → Login ด้วย GitHub → **Add New → Project**
2. เลือก repo `yimsai-shop` → Framework: **Other** → **Deploy**
3. ได้โดเมน เช่น `yimsai-shop.vercel.app` (แก้ไฟล์ใน GitHub → Vercel อัปเดตเอง)

## วิธีใช้หลังบ้าน (`/admin.html`)
ใส่รหัส `ADMIN_KEY` แล้วทำตามแท็บ:

1. **หยิบสินค้า** — รวมยอดทุกออเดอร์เรียงตามชั้นวาง + แยกใส่ตะกร้าตามออเดอร์ → พิมพ์ → กด *หยิบครบแล้ว*
2. **แพ็คสินค้า** — สแกน/พิมพ์ SKU แล้ว Enter (หรือคลิกที่สินค้า)
   - ❌ เตือนถ้า **หยิบผิด** หรือ **เกินจำนวน**
   - ครบแล้วจึงกด *ปิดกล่อง* ได้
3. **ใบปะหน้า** — ขนาด 10×15 ซม. (ผู้ส่ง/ผู้รับ/รหัสไปรษณีย์/COD/บาร์โค้ด) → พิมพ์ → ใส่เลขพัสดุ → *บันทึกส่งแล้ว*

สถานะ: `ใหม่ → หยิบแล้ว → แพ็คแล้ว → ส่งแล้ว` (หรือ `ยกเลิก`) — ทุกอย่างบันทึกกลับลง Google Sheet

## เพิ่ม/แก้สินค้า
แก้ 2 ที่ให้ **SKU และราคาตรงกัน**: `config.js` (PRODUCTS) และ `Code.gs` (PRODUCTS) → ใส่รูปใน `images/products/`
ถ้าเพิ่ม SKU ใหม่หลังมีออเดอร์แล้ว ให้เพิ่มคอลัมน์ชื่อ SKU นั้นในแถวหัวตารางของชีตด้วย
